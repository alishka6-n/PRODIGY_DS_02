# PRODIGY_DS_02

## Task 2: Data Cleaning and Exploratory Data Analysis (EDA)

### Objective
Perform data cleaning and exploratory data analysis on the Titanic dataset to identify patterns, trends, and relationships between variables.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Steps Performed
1. Loaded and explored the dataset
2. Checked missing values
3. Performed data cleaning
4. Conducted univariate and bivariate analysis
5. Visualized relationships using graphs and heatmaps
6. Derived insights from the dataset

### Key Insights
- Female passengers had higher survival rates.
- Higher-class passengers showed better survival chances.
- Most passengers belonged to Passenger Class 3.
- Fare column contained outliers.
- Age and survival patterns showed noticeable trends.

### Conclusion
The analysis revealed that gender, passenger class, and age significantly influenced passenger survival outcomes on the Titanic.
